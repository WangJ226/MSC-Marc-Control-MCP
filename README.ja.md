# MSC Marc Control MCP 1.3.2

**配布状況：1.3.2 のインストーラーは現在未公開です。開発と検証を進めた後に公開します。**

**AI アシスタントをローカルの Marc/Mentat に接続し、入力確認・モデル操作・結果整理を支援します。**

[中文](README.zh-CN.md) · [English](README.md) · [ダウンロード](https://github.com/WangJ226/MSC-Marc-Control-MCP/releases) · [導入手順](docs/trial-ja.md)

Marc を利用する研究者・学生・技術者向けの Windows アプリです。WorkBuddy、Codex、Claude Desktop から MCP ツールを呼び出し、実際の結果を確認できます。

| 作業 | 実装済みの機能 | 得られるもの |
|---|---|---|
| 環境確認 | Marc 自動検出、接続設定、診断出力 | 状態と診断 JSON |
| 入力確認 | DAT、材料・集合、接触、insert、ばね、サブルーチン依存関係の監査 | 構造化された確認結果 |
| モデル操作 | 集合の照会、指定荷重・拘束、材料・形状パラメータ、ジョブ作成 | 操作結果や入力ファイル |
| 求解の調査 | ジョブ追跡、ログ解析、進捗とホットスポット整理 | 状態記録と調査の手がかり |
| 後処理 | T16 履歴・極値、CSV 曲線、履歴・パス出力、画像保存 | ツールに応じた表・曲線・画像 |

174 のツール入口を持ち、各機能には入力と実行条件があります。小さなモデル副本や既存ログから始め、変更・起動・求解を確認して進めてください。

Windows、有効な Marc/Mentat ライセンス、AI クライアントとアカウントを用意します。MCP 用 Python は同梱です。Marc 2016–2025 は適応対象範囲、2024/2025 は優先対象で、個別環境の確認が必要です。

1.3.2 は外部製品の自動テスト296件、パッケージ・認証・3言語画面・更新確認を完了しました。開発者の Windows では環境確認と Mentat 空モデルの起動・終了を検証しています。顧客の Windows、3種類の AI クライアントを通した操作、複雑な解析は引き続き実例を収集します。

モデルと結果はローカルに保存されます。AI に渡す内容は利用する AI サービスの規約・データ方針に従います。解析条件と結論は利用者が確認してください。公開 Issue は個人情報・認証コード・機密モデルを除いて投稿してください。

公開 Release 一覧が空の場合は [連絡先](docs/contact.md) で案内を受けられます。本リポジトリは紹介資料と配布入口を公開し、アプリのソースは非公開で管理しています。

# MSC Marc Control MCP 1.3.2 — 版本说明

2026-11-05。1.3.2 安装包按维护者安排暂缓公开上传，完善和验证后发布。完整 Windows 安装包，中文、英文、日文界面，连接 WorkBuddy、Codex 与 Claude Desktop。

## 本版重点
- 提供诊断导出，便于定位安装与环境问题。
- 完善在线授权与兑换码接入流程。
- 修复冻结程序动态执行模块打包遗漏，增加包审计检查。
- 验证原目录升级保留设置与授权状态。

## 功能与成果
提供输入文件和模型审计、确认后的模型操作、作业跟踪与日志诊断、T16/CSV 后处理及曲线导出工具。输出随所选工具和输入数据而定，见 [功能表](../README.zh-CN.md)。

## 验证范围
296项外部产品自动回归通过；完成包审计、在线授权与兑换协议、三语言窗口和升级检查。本机正式 EXE 完成环境检查及 Mentat 隔离空模型启动/退出。协议模拟与本机实际运行分别记录。

独立客户 Windows、真实 AI 客户端完整操作与复杂工程求解继续收集证据。共享服务测试有3项既有配额断言差异，在原服务对照同样复现，独立于上述296项外部产品测试。

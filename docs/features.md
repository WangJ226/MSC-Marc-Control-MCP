# Marc MCP：功能、输入与成果

[产品首页](../README.zh-CN.md) · [首次使用](trial-install.md) · [验证范围](changelog.md)

以下按实际工具实现介绍能力。工具入口、自动测试、本机运行和客户工程验收分别记录；选择功能时结合输入、许可证、版本与项目条件。

## 01 · 先把环境接通

**适合：** 首次安装、换电脑、排查路径与 AI 接入问题。

软件查找 Marc 安装，提供客户端配置与诊断导出。`run_mcp_doctor` 检查环境；配置完成后由 AI 发起真实调用确认链路。

**输入：** 已安装的 Marc/Mentat、有效许可证及 AI 客户端。

**成果：** 结构化检查状态和诊断 JSON，帮助识别待处理条件。MCP Python 随包提供，减少手工准备运行环境的步骤。

## 02 · 检查已有模型，减少盲目修改

**适合：** 接手 DAT、核对材料分配、调查接触或拓扑问题。

| 工具入口 | 用途 |
|---|---|
| `audit_marc_dat_deck_summary` | 输入文件摘要 |
| `audit_dat_set_material_membership` | 材料与集合归属检查 |
| `audit_contact_topology` / `audit_insert_topology` | 对应拓扑检查 |
| `audit_dat_springs` | 弹簧定义检查 |
| `audit_fortran_user_subroutine_dependencies` | 用户子程序依赖检查 |

**输入：** 工具支持的文件、依赖与检查范围。

**成果：** 审计结果与待核查项；适用的候选生成工具还可建立变体，供你比较和选择。检查结果帮助缩小排查范围，物理合理性由工程分析确认。

## 03 · 把重复模型操作变成明确任务

**适合：** 对已有模型重复设置荷载、约束、参数或输出作业。

可查询在线模型与集合、按包围盒选节点，创建支持的连接，设置指定节点集位移约束和载荷、边/面荷载，更新材料与几何参数，创建静力作业及导出 Marc 输入。

代表入口：`queue_live_model_inventory`、`queue_query_live_sets`、`queue_update_material_parameter`、`queue_create_static_job`、`queue_write_marc_input`。

**输入：** 项目副本、对象/集合、参数值、单位及预期变更。在线操作需要可用的 Mentat 会话或工作进程。

**成果：** 操作返回、生成的输入及可核对的模型状态。提交任务后核对执行结果；模型修改和启动先经过用户确认。

## 04 · 跟踪求解，让排查有依据

**适合：** 长时间运行、出现退出信息、定位进度与异常。

`run_marc_solver_job` 与后台作业工具提供执行与跟踪；`parse_solver_logs`、`summarize_solver_progress` 整理日志和增量进度；`map_solver_hotspots_to_dat` 在输入条件满足时关联热点与 DAT。

**输入：** 对应输入与日志、目标运行目录、求解参数和执行批准。

**成果：** 作业状态、进度摘要和诊断线索。退出状态、收敛表现与工程验收分别核对，日志线索用于指导后续检查。

## 05 · 从结果文件提取真正需要的数据

**适合：** 重复提取节点历史、比较峰值、整理曲线或模型图像。

| 工具入口 | 用途 |
|---|---|
| `inventory_t16_file` | 清点结果文件 |
| `extract_t16_node_history` | 指定节点历史 |
| `extract_t16_scalar_extrema` / `extract_t16_tensor_extrema` | 适用变量的极值 |
| `plot_t16_node_history` | 绘制所选节点历史 |

另有 CSV 曲线提取与分析，以及会话中的历史曲线、路径曲线、当前 XY 图和图形快照导出。

**输入：** 结果文件、节点/变量、方向、范围与单位约定。T16 工具需要相应 Marc 后处理环境，在线导出需要就绪的会话。

**成果：** 对应工具支持的数据表、曲线、图像和结构化结果。保留原始文件与提取条件，复核单位、坐标系和取值位置后用于分析或汇报。

## 用一个小任务检验价值

选择脱敏副本 → 检查环境 → 确定输入和目标 → 调用工具 → 打开实际输出 → 反馈结果。

建议从只读 DAT 审计或已有日志整理开始。复杂工程及三个真实 AI 客户端的完整使用证据仍在收集；[版本说明](changelog.md) 列出本机验证范围。

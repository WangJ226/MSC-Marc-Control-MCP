# 常见问题

## 能解决哪些问题？
适合输入文件审计、明确范围的模型操作、求解日志排查与结果提取。详见 [功能与成果表](../README.zh-CN.md)。先从自己的小任务检验价值。

## 是否需要懂 Marc？
需要具备任务所需的建模与分析基础。用户决定工程假设、单位、边界条件及结果解释，AI 帮助组织工具调用。

## 安装环境会自动配置吗？
软件包含 MCP Python 环境，提供 Marc 自动发现、环境检查及 AI 客户端配置。Marc/Mentat 安装及许可证、AI 账户登录和信任确认由用户准备。多个 Marc 版本需选择目标版本。

## 支持哪些客户端和 Marc 版本？
提供 WorkBuddy、Codex、Claude Desktop 接入。Marc 2016–2025 是适配范围，2024/2025 优先。配置和协议检查与实际客户端验收分别记录，具体电脑需现场验证。

## 是否能保证一次完成任意模型？
复杂模型依赖材料、接触、网格、边界条件及收敛设置。工具返回状态和证据，用户据此决定后续操作。首次使用从项目副本开始。

## 当前测到了什么程度？
1.3.2 完成296项外部自动回归、打包、授权协议、三语言及升级检查；本机完成正式 EXE 环境检查和 Mentat 空模型启动/退出。独立客户、真实 AI 客户端完整流程和复杂求解继续收集证据。

## 下载入口为什么可能没有安装包？
[Releases](https://github.com/WangJ226/Marc-MCP-Assistant/releases) 保留为发行入口。当前公开列表为空，联系提供方获取体验安排；源码归档仅包含本公开仓库的资料。

## 怎样开始体验？
通过 [联系入口](contact.md) 提供版本信息和一个简短任务。提供方人工确认体验安排并发放授权，期限以授权记录为准。

## 数据会发到哪里？
模型与结果在本机处理。授权服务处理必要的账户、设备与授权信息。AI 客户端可能发送提示、工具结果或选定文件给其模型服务，使用前确认项目保密要求。详见 [隐私说明](privacy.md)。

## 遇到问题如何反馈？
记录版本、步骤、期望与实际结果，导出并检查诊断文件。公开 Issue 使用脱敏信息，授权码与客户资料通过私人渠道处理。
